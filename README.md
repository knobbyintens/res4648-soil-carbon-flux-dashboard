# Soil Carbon Flux Dashboard

**Citation:** Ibrahim, S., & Petrova, L. (2026). Soil Carbon Flux Dashboard. Soil Science Letters, 8(1), 33-47.
**Maintainer:** Research Software Group (software@cedarbrook-research.org)
**Project ID:** RES-4648-SOIL

## Repository Status
To be released. This repository is currently a planning scaffold; the implementation will be published after the internal review completes.

## Overview
A dashboard for visualizing chamber-based soil carbon flux measurements alongside soil temperature and moisture series.

## Repository Layout
- `src/` — source code
- `data/` — input datasets and schema notes
- `experiments/` — experiment configuration files
- `notebooks/` — exploratory analysis notebooks
- `tests/` — smoke tests

## Usage
See the experiment configuration files under `experiments/` for the supported runs.
